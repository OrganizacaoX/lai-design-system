LAI Design System

Registry shadcn com os componentes de UI, hooks e o tema do LAI.

Configure o namespace @lai no components.json do seu projeto:

"registries": {
  "@lai": "/r/{name}.json"
}

Depois:

npx shadcn@latest add @lai/theme @lai/button @lai/sidebar

Fonte / manutenção: github.com/OrganizacaoX/lai-design-system
